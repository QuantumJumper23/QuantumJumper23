<h3><a href="https://github.com/QuantumJumper23/Shell-Mind-Agent">Shell Mind Agent</a></h3>
<p>A terminal coding agent built with TypeScript and Bun.</p>
<ul>
  <li>Conversational agent loop with history retained throughout a session.</li>
  <li>Tools for reading, writing, and editing files.</li>
  <li>Shell-command execution and filesystem search.</li>
  <li>Integration with OpenAI-compatible model APIs.</li>
  <li>Command checks, confirmation prompts, and tool-loop iteration limits.</li>
  <li>Can be compiled into a standalone executable with Bun.</li>
</ul>
<p><strong>TypeScript · Bun · AI agents · Tool calling</strong></p>

<h3><a href="https://github.com/QuantumJumper23/Insta-Search-IN-PROGRESS">Insta Time Search</a> · In progress</h3>
<p>A browser extension exploring date-based discovery of Instagram posts.</p>
<ul>
  <li>React popup for opening an Instagram profile by username.</li>
  <li>TypeScript scripts for extracting post captions, timestamps, and links from Instagram responses.</li>
  <li>Local post-storage implementation using Dexie and IndexedDB, with integration still in progress.</li>
  <li>Date-based post filtering and search planned.</li>
</ul>
